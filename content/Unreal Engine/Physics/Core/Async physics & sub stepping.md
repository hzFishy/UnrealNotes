# Enable Async creation state
For 5.6 and above
Use `p.Chaos.EnableAsyncInitBody = true`

## Info
- `Substepping Async` is not used anymore and should be deprecated.
- `Substepping` and `Async Phyiscs` are mutually exclusive.
- [Relationship between `Tick Physics Async` and `Substepping`](https://forums.unrealengine.com/t/relationship-between-tick-physics-async-and-substepping/2395435)
- [Is Async Physics Tick really async?](https://forums.unrealengine.com/t/is-async-physics-tick-really-async/2353151)
